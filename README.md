# Odin Recipes

A simple recipe website project built with basic HTML knowledge from [The Odin Project](https://www.theodinproject.com/) Foundations course.

## Project Overview

This project demonstrates fundamental HTML skills including:

- Creating semantic HTML structure
- Using headings, paragraphs, and lists
- Creating links between pages
- Organizing content with proper HTML hierarchy

## Features

- **Home Page**: Main landing page with links to various recipes
- **Recipe Pages**: Individual pages for each recipe containing:
  - Recipe title and description
  - Ingredients list
  - Step-by-step cooking instructions
  - Basic CSS styling (pure HTML)
